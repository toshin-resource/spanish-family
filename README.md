# はじめのスペイン語 — 単語・日常フレーズ学習アプリ

iPhoneのSafariで使う、家族向けのスペイン語学習Webアプリです。
仕様書（spanish_vocabulary_app_spec.md）の「初期版」の範囲を実装しています。

**公開URL：https://toshin-resource.github.io/spanish-family/**（iPhoneのSafariで開く）

## すぐに試す（パソコン）

インストール不要です。このフォルダで次を実行し、ブラウザで http://localhost:8000 を開きます。

```bash
python -m http.server 8000
```

記録の保存先はクラウド（Googleスプレッドシート）です。開くと自動でつながり、合言葉の入力は不要です。
回答は端末にためておき、10問ごと・セットの終わり・ホームに戻ったとき・アプリを閉じたときに、まとめてクラウドへ送ります。インターネットにつながっていないときは、つながったら自動で送ります（画面右上に件数を表示）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `css/style.css` | 画面の骨組みとアルゼンチン風の見た目（水色・白・金色の太陽） |
| `js/app.js` | 各画面と操作 |
| `js/learn.js` | 判定・選択肢・自動復習・今日の○問・集計のルール。暫定の数値は先頭の `RULES` で変更できます |
| `js/store.js` | 端末内保存とクラウド保存（送信待ち・再試行） |
| `js/speech.js` | 発音の読み上げ・音声入力（Web Speech API） |
| `js/data-words.js` | 単語マスター（基本300語） |
| `js/data-phrases.js` | フレーズマスター（8場面・80表現） |
| `config.js` | Apps Script のURL（任意） |
| `gas/Code.gs` | 記録保存サーバー（Google Apps Script） |

## クラウド保存の準備（Googleスプレッドシート）

家族で記録を共有したり、別の端末で続きをするための設定です。一度だけ行います。

1. Googleドライブで新しいスプレッドシートを作ります（名前の例：「スペイン語 学習記録」）。**共有やWeb公開はしません。**
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの `gas/Code.gs` の内容を貼り付けて保存します。
4. 上部の関数の選択で `setup` を選んで「実行」します。初回は権限の確認が出るので、自分のアカウントで許可します。
   スプレッドシートに `users`・`progress`・`answers` の3つのシートができます。標準では合言葉なしで使えます。
5. （任意）合言葉を付けたいときは関数 `enableFamilyKey` を実行します（合言葉が作られ、実行ログに表示されます）。アプリには最初に入力画面が出るようになります。やめるときは `disableFamilyKey` を実行します。
6. 右上の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選び、
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   にして「デプロイ」します。表示された **ウェブアプリのURL（…/exec）** を控えます。
   ※「全員」にするのは、家族のiPhoneからGoogleログインなしで送れるようにするためです。合言葉なしの場合、URLを知っている人は家族の名前と学習状況を見たり記録を追加したりできます（スプレッドシート自体は非公開のまま）。
7. 表示されたURLを `config.js` の `GAS_URL` に書きます。家族の各端末では、アプリを開くだけでクラウドにつながります（合言葉を付けた場合だけ、最初に入力します。**合言葉は config.js に書かないでください**）。

- クラウドにつなぐ前にその端末で登録した人の記録は、接続したときにそのままクラウドへ引き継がれます。
- 別の端末では、新しく登録せずに一覧から自分の名前を選ぶと、記録が読み込まれます。
- `gas/Code.gs` を直したときは「デプロイ」→「デプロイを管理」→ 編集 →「新しいバージョン」で更新します（URLは変わりません）。

## iPhoneで使えるように公開する（GitHub Pages）

1. GitHubで新しいリポジトリを作り、このフォルダの中身をアップロードします（`.claude` フォルダは不要です）。
2. リポジトリの「Settings」→「Pages」で、Branch を `main`・フォルダを `/ (root)` にして保存します。
3. 数分後に表示される `https://（ユーザー名）.github.io/（リポジトリ名）/` をiPhoneのSafariで開きます。
4. アプリの「ホーム画面に追加する方法」の手順でホーム画面に追加できます。

公開されるのはアプリと単語データだけです。学習記録はスプレッドシートに保存され、GitHubには入りません。

## 実装した主な機能

- 利用者の登録・選択（内部は固有ID）、利用者ごとの記録・設定
- 覚えた単語数を大きく表示するホーム、基本300語に対する進捗
- 単語学習／日常フレーズ集、スペイン語→日本語・日本語→スペイン語・ミックス
- 選択式（4択／5択）と日本語入力式（キーボード・音声入力ボタン）
- 「わからない」と、3問挟んだ後の再出題（1回の学習で同じ問題は最大2回まで）
- 入力式の判定：登録した訳・言い換えは自動で正解、別の語の意味なら不正解と説明、判断できない答えは「確認待ち」にして本人が選ぶ
- 自動復習（正解が続くと 1→3→7→14→30→60→120日、間違えると翌日）
- 聞き取りクイズ（回答前は文字を隠す・再生できないときは不正解にしない）
- 今日の○問（期限の来た復習を優先し、空きに新しい語を追加・中断と再開）
- 単語リスト（絞り込み・発音）、場面別フレーズ一覧
- 設定（問題数・選択肢数・発音の速さ・声・復習予定）
- クラウド保存（送信待ちの表示と自動再試行・二重保存の防止）、記録の書き出し
- ホーム画面への追加方法の案内

## 暫定で決めたこと（仕様書の「要決定」項目）

変更したい場合は `js/learn.js` の `RULES` や該当箇所を直します。

| 項目 | 今の動き |
| --- | --- |
| 習得済みの条件 | 別々の学習回で3回続けて正解。同じ学習回の中の再出題での正解は数えない |
| 習得済みの語を間違えたとき | 「学習中」に戻し、翌日に復習 |
| 本人が「正解として記録」した答え | 正解として扱う（判定方法は「本人確認」として履歴に残る） |
| 覚えた単語数 | スペイン語→日本語（文字あり）で習得済みの単語の数。日本語→スペイン語・聞き取り・フレーズは別に表示 |
| ミックス | 両方向をほぼ半分ずつ。選択式のみ |
| 家族へのアクセス | 合言葉なし（利用者の希望）。必要になったら `enableFamilyKey` で合言葉を付けられる |
| 単語データの置き場所 | アプリと同じ場所（`js/data-words.js`）。記録だけをスプレッドシートに保存 |
| 例文・IPA・冠詞の読み上げ | 例文とIPAは未実装（データ項目の追加は可能）。冠詞は表示のみで、読み上げは単語だけ |

## まだ確認できていないこと

- **iPhone実機での確認はまだです。** 読み上げの声・音声入力（マイクと音声認識の許可）・ホーム画面から開いたときの動作は、実機で確かめる必要があります。
- **Apps Script のサーバーは、Google上ではまだ動かしていません。** アプリ側の送信・再試行は模擬サーバーで確認済みです。上の手順で設定した後、2台の端末で同じ人を選んで記録が引き継がれるかを確認してください。
- 単語・フレーズの選定と訳は仮のものです。使用頻度の出典の確認や、訳・言い換えの見直しが必要です。
